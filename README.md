# R Surabhi — Personal Portfolio

A personal portfolio showcasing my projects, technical skills, academic journey, and extracurricular activities.

Built with a focus on interactive design, visual storytelling, and exploring modern web technologies.

## About the Project

This portfolio brings together my work in Python, machine learning, data science, privacy engineering, and full-stack development.

It also highlights my academic background, hackathon experience, certifications, and involvement in campus activities.

## Design & Technologies

- **Color Palette:** Sage green, warm beige, burgundy, and dark backgrounds.
- **Typography:** Syne, Plus Jakarta Sans, JetBrains Mono, and Cinzel.
- **Frontend:** React, Vite, JavaScript, and CSS.
- **Animations & Graphics:** Three.js, WebGL, particle effects, and interactive transitions.
- **Visual Effects:** Mouse-responsive elements, parallax movement, and animated backgrounds.
- **Audio:** Web Audio API for subtle interface sound effects.

## Features

- Animated hero section with interactive 3D graphics.
- About section covering my technical interests and extracurricular activities.
- Skills section showcasing programming languages, frameworks, and tools.
- Interactive privacy sandbox demonstrating PII detection and data anonymization concepts.
- Project showcases featuring PhishGuard, Dataset Privacy & Intelligence Guardian, and SunSafe.
- Academic and extracurricular journey with an interactive timeline.
- Hackathon achievements and certifications.
- Resume preview and print functionality.
- Contact section with email, phone, and social links.
- Responsive layouts for desktop and mobile devices.

## Projects Featured

**Dataset Privacy & Intelligence Guardian**
A Python-based platform for dataset profiling, sensitive information detection, anonymization, and privacy risk assessment.

**PhishGuard**
An AI-powered phishing detection platform that uses machine learning and threat intelligence APIs to analyse suspicious URLs and email content.

**SunSafe**
A UV awareness platform that retrieves location-based UV index data and displays current and historical readings.

## Running Locally

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## Deployment

The portfolio can be deployed using Vercel or other platforms supporting Vite applications
